## 1. Реестр волны 1 (задача → решение → критерий приёмки)

### ENG-1 · P1 — Кэш шрифтов pdf-lib: повторный PDF того же языка битый
- **Локация:** `src/lib/docgen/pdf.ts:30,39-54`
- **Проблема:** модульный кэш хранит объекты `PDFFont`, привязанные к первому
  `PDFDocument`; второй документ получает ссылки на ресурсы чужого контекста
  (воспроизведено аудитом: 1-й PDF 14 285 б с 2×/FontFile2, 2-й — 1 417 б, 0 шрифтов).
- **Решение:** кэшировать **байты** (`Uint8Array`) шрифтов по `DocLang`; `embedFont`
  вызывать для каждого нового `PDFDocument`; объекты не кэшировать.
- **Критерий:** юнит-тест «10 повторных генераций PDF (zh) подряд в одном процессе» —
  каждый валиден: размер > 8 КБ, `pdf-lib`-парсинг без ошибок, `document.context` содержит
  ≥1 объект /FontFile2 (эмпирическая сверка pdftoppm — прогон вручную/скриптом).

### LEG-1 · P1 — RFN «Noto» в подмножествах (нарушение SIL OFL 1.1 §3)
- **Локация:** `public/fonts/DocGen{Zh,Ja,Ko}-{Regular,Bold}.ttf` (6 файлов);
  причина — `tools/make-cjk-fonts.py:135-142` (`--name-IDs=*`)
- **Проблема:** внутри nameID 1/4 = «Noto Serif JP Bold», nameID 6 = «NotoSerifJP-Bold» —
  Modified Version использует Reserved Font Name → ничтожность лицензии §TERMINATION,
  блокирует дистрибутивы Linux.
- **Решение:** скрипт переименования nameID 1/3/4/6/16/17 → «DocGen Serif Zh/Ja/Ko …»
  (nameID 0/13/14 — авторская атрибуция §2/§4 — сохраняется); вшить переименование в
  `make-cjk-fonts.py`; CI-гейт `tools/check-font-names.py --check` (fontTools: RFN «Noto»
  не встречается в nameID 1/4/6).
- **Критерий:** дамп name-таблиц 6 файлов: в nameID 1/4/6 нет подстроки «Noto»;
  CI-шаг зелёный; атрибуция (nameID 0/13/14) сохранена.

### LEG-2 + LEG-4 · P1/P2 — GPL-текст и OFL-текст рядом со шрифтами
- **Локация:** `public/fonts/` (FreeSerif-{Regular,Bold}.ttf 5,7 МБ, Liberation*, DocGen*)
- **Проблема:** FreeSerif (GPLv3 + шрифтовое исключение) конвейируется в 6 каналах
  без текста лицензии и source-offer (§4–§6 GPLv3); SIL OFL 1.1 §2 требует текст
  лицензии с каждой копией шрифта.
- **Решение:** добавить в `public/fonts/`: `OFL-1.1.txt`, `gpl-3.0.txt`,
  `README-fonts.txt` (уведомление: FreeSerif — GPLv3+font exception,
  source: https://www.gnu.org/software/freefont/; Liberation — OFL 1.1;
  DocGen Serif Zh/Ja/Ko — Modified Version Noto Serif, SIL OFL 1.1).
  Папка `public/` автоматически попадает в out/ → web.zip, APK, установщики.
  Стратегическая замена FreeSerif на Noto Serif Armenian/Hebrew — Волна 2.
- **Критерий:** три файла присутствуют в `out/fonts/` после `next build` и в web.zip.

### TPL-1 · P2 — «Мёртвые» поля формы (210: значение не попадает в документ)
- **Локация:** все 43 модуля `src/data/templates/`; гейт — `tools/check-data.ts`
- **Проблема:** поля формы (по умолчанию required), чьи `{{id}}` не встречаются в теле:
  пользователь обязан заполнить значение, которое молча исчезает (персональные номера
  Швеции/Норвегии, телефоны Бельгии, AFM Греции, должность РФ и др.).
- **Решение:** (1) расширить `tools/check-data.ts` правилом «каждое поле → хотя бы один
  плейсхолдер в теле»; (2) закрыть 210 случаев: для идентификаторов/контактов — добавить
  плейсхолдер в тело (шапка/подпись, язык документа), для дублирующих/избыточных —
  удалить поле. Приоритет: se/no/fi/gr/be (персональные номера и контакты).
- **Критерий:** `bun tools/check-data.ts` зелёный; цензус-скрипт даёт 0.
