# DocGen

**DocGen** — приложение для генерации официальных документов по шаблонам: заявления, жалобы, претензии, иски, расписки, доверенности, запросы медицинских записей и обращения в ведомства. Работает **полностью офлайн**: каталог встроен в приложение, а документы (.docx/.pdf) собираются прямо на устройстве — без сервера, без аккаунтов, без отправки данных куда-либо.

**38 стран** — Россия и СНГ, США, Великобритания, Канада, Индия, Германия, Австрия, Швейцария, Франция, Испания, Италия, Польша, Нидерланды, Бельгия, Португалия, Швеция, Норвегия, Дания, Финляндия, Греция, Китай, Япония, Южная Корея, Турция, Израиль, Мексика, Бразилия, Аргентина, Австралия. Каждый шаблон принадлежит ровно одной стране и написан по её правовым стандартам: ТК РФ и ЗоЗПП, ТК РК и ТК РБ, КЗпП и Закон «Про відпустки», Əmək Məcəlləsi, BGB и Bundesurlaubsgesetz, AngG и KSchG, OR и SchKG, ABGB и MRG, Code du travail и Code de la consommation, Estatuto de los Trabajadores и Ley 3/2014, Codice Civile и Codice del Consumo, Kodeks pracy, BW 7 (нидерландский Burgerlijk Wetboek), Loi du 3 juillet 1978 (Бельгия), Código do Trabalho и NRAU (Португалия), Semesterlagen и LAS (Швеция), Ferieloven и Arbeidsmiljøloven (Норвегия), Ferieloven и Funktionærloven (Дания), Vuosilomalaki и Työsopimuslaki (Финляндия), Гражданский кодекс Греции и π.δ. 741/2016, 劳动合同法 и 消费者权益保护法, 労働基準法, 근로기준법, İş Kanunu № 4857 и TKHK № 6502, חוק חופשה שנתית, Employment Rights Act 1996 и Consumer Rights Act 2015, Canada Labour Code и Consumer Protection Act, Employment Rights Act/EPF Act и Consumer Protection Act 2019, CLT и CDC, Ley Federal del Trabajo и LFPC, Ley 20.744 и Ley 24.240, Fair Work Act и Australian Consumer Law.

**Разделение языков** — ключевое правило DocGen: язык, выбранный при первой настройке, управляет **только интерфейсом** (языки всех стран каталога). **Страна** определяет, какие шаблоны доступны и на каком языке они создаются — на государственном языке выбранной страны (Азербайджан → документ на азербайджанском, интерфейс — какой выбрали).

## Как это работает

| Этап | Что происходит |
|---|---|
| Первая настройка | Два выбора: **язык интерфейса** (языки всех стран каталога) и **страна** (38 стран, поиск по названию, группировка по регионам). Язык — только язык кнопок и подписей; страна — набор шаблонов и язык будущих документов |
| Каталог | Дерево категорий: работа, суды и правовая защита, медицина, образование, почта, ЖКХ, универсальные документы. Показаны шаблоны выбранной страны; у каждого — тип: стандартный / только «от руки» / только через госпортал |
| Форма | Поля под шаблон (текст, дата, выбор), образцы значений на языке документа; вверху — уведомление, на каком языке создастся документ |
| Экспорт | .docx (Times New Roman 14 pt / 宋体 / ＭＳ 明朝 / 바탕 / David, поля по ГОСТ Р 7.0.97-2016, полуторный интервал) и .pdf (встроенные юникод-шрифты: кириллица, армянский, иврит с BiDi, китайский, японский, корейский); печать — чистой страницей документа |
| Спец-экраны | Красное предупреждение для шаблонов «только от руки» (бланки строгой формы); карточка госпортала со ссылкой для вопросов, которые решаются только онлайн |

## Ключевые возможности

- **Каталог по странам** (38 стран) — у каждой страны свой набор шаблонов: заявления работодателю (отпуск, увольнение, справки), досудебные претензии, исковые заявления, расписки о займе, доверенности, заявления в школу, жалобы на медицинскую помощь, требования о ремонте жилья — плюс карточки официальных госпорталов (Госуслуги, eGov, Е-Паслуга, Дія, my.gov.uz, Түндүк, e-gov.am, mygov.az, servicii.gov.md, USA.gov, bund.de, GOV.UK, canada.ca, india.gov.in, administracion.gob.es, gob.mx/PROFECO, italia.gov.it/SPID, oesterreich.gv.at, ch.ch, service-public.fr, obywatel.gov.pl, Rijksoverheid/MijnOverheid, belgium.be, gov.pt/ePortugal, Skatteverket/Försäkringskassan, Altinn/NAV, borger.dk/skat.dk, Suomi.fi/Kela, gov.gr/AADE, 12315, マイナポータル, 정부24, e-Devlet, gov.il, consumidor.gov.br, Argentina.gob.ar, myGov/ACCC).
- **Язык документа = государственный язык страны** (ru, uk, be, kk, uz, kg, tg, hy, az, ro, de, fr, pl, en, zh, ja, ko, tr, he, pt, es, it, nl, sv, no, da, fi, el): тела шаблонов, образцы значений и варианты выбора — на государственном языке; даты форматируются по правилам языка («02 ноября 2026 г.» / «2. November 2026» / «15 marzo 2026» / «1 januari 2026» / «1. tammikuuta 2026» / «1 Ιανουαρίου 2026» / «2026年11月2日» / «02.11.2026»).
- **Правовые основания**: каждый шаблон ссылается на конкретные нормы (статьи кодексов и законов своей страны); там, где форма решена онлайн — карточка госпортала вместо бумажного шаблона.
- **Три типа шаблонов**: STANDARD (скачивайте и подавайте), HANDWRITTEN_REQUIRED (красный экран: «заполняется только от руки» — например, бланк почтового перевода ф. 112ЭП или reconnaissance de dette по Cerfa 15399), GOV_PORTAL_ONLY (карточка официального портала).
- **Экспорт**: .docx и .pdf прямо в браузере/на устройстве; PDF-шрифты — подмножества Liberation Serif (кириллица), FreeSerif (армянский, иврит), Noto Serif SC/JP/KR (китайский, японский, корейский); иврит корректно обрабатывается с учётом направления письма (BiDi).
- **Автономность**: нет ни одного сетевого запроса ради работы приложения (только сознательные переходы на госпорталы по ссылкам); данные не покидают устройство.

## Скачать

Готовые сборки — в разделе **[Releases](https://github.com/RVMXL/DocGen/releases)**. Единый выпуск собирается и публикуется CI по пушу тега `v*`. История изменений по версиям — в [`CHANGELOG.md`](CHANGELOG.md) и примечаниях к релизам.

| Артефакт | Платформа | Что это |
|---|---|---|
| `DocGen-<ver>-win64-setup.exe` | Windows 10/11 (x64) | Установщик: автономное настольное приложение |
| `DocGen-<ver>-linux-x64.AppImage` | Linux (x86_64) | Portable-сборка: запустил — работает |
| `DocGen-<ver>-linux-x64.deb` | Debian/Ubuntu (x64) | Пакет для установки |
| `DocGen-<ver>-mac-arm64.dmg` | macOS Apple Silicon (M1–M4) | Автономное приложение (добавляется в релиз отдельной джобой и может появиться чуть позже остальных) |
| `DocGen-<ver>-android.apk` | Android 8.0+ (ARM64) | Приложение, работает полностью офлайн |
| `DocGen-<ver>-web.zip` / `.tar.gz` | любая ОС | Статический сайт: распакуйте и разверните на любом хостинге (инструкция внутри: `deploy/README-DEPLOY.txt` и в репозитории) |

Генерация документов выполняется на устройстве (docx + pdf-lib в WebView/браузере) — сервер не нужен ни для одной платформы.

**iOS**: сборки нет. Публикация iPhone-приложения требует аккаунта Apple Developer Program (99 $/год), macOS с Xcode и подписи сертификатами Apple — установка «мимо App Store» без аккаунта невозможна в принципе. Пока iOS-версии нет, web-версия открывается в Safari; если аккаунт Apple Developer появится, сборка добавляется в этот же релизный конвейер.

## Развёртывание web-версии

Архив `DocGen-<ver>-web.zip` — обычные статические файлы. Любой хостинг подойдёт:

```nginx
server {
    listen 80;
    server_name docgen.example.com;
    root /var/www/docgen;      # распакованный zip
    index index.html;
    location / { try_files $uri $uri/ /index.html; }
}
```

Caddy, Apache, GitHub Pages, Docker-образ с nginx, Cloudflare Pages — примеры в [`deploy/README-DEPLOY.txt`](deploy/README-DEPLOY.txt).

## Сборка из исходников

Требуется [Bun](https://bun.sh) 1.2+ (или Node.js 20+ с npm).

```bash
bun install
bun tools/check-data.ts   # проверка целостности каталога шаблонов
bun run build             # next build → статический сайт в out/
bun run dev               # режим разработки на http://localhost:3000
```

Каталог шаблонов — статические TypeScript-модули в `src/data/templates/` (по файлу на страну). Добавление страны: файл `src/data/templates/<cc>.ts` + запись в `src/data/countries.ts` + агрегация в `src/data/catalog.ts`. Проверка: `bun tools/check-data.ts`.

Android: `bun run build && bunx cap sync android` → `android/` собирается в Android Studio или `./gradlew assembleRelease` (подпись — через `keystore.properties`, см. `.github/workflows/release.yml`).

Desktop: `bun run build && node tools/prepare-desktop.mjs && cd desktop && npx electron-builder --win|--linux|--mac`.

## Android

- Подпись релизных APK — стабильным upload-ключом (RSA-4096, срок 30 лет). **SHA-256 сертификата:** `9F:B0:27:A8:A4:EE:DA:28:13:AF:6A:74:26:1B:B0:87:C0:9B:C7:3B:B0:AF:2B:C0:50:C1:5F:ED:B6:1B:1F:46`. Обновления ставятся поверх установленных версий; если установка предупреждает о подписи — значит, APK получен не из официального релиза.
- Ключ хранится только в GitHub Secrets репозитория; в git он не попадает (`.gitignore`). Потеря ключа = невозможность обновить приложение поверх установленного, поэтому резервная копия ключа — на ответственности владельца.
- Приложению нужен только доступ в интернет для открытых по ссылке госпорталов; генерация документов выполняется офлайн.
