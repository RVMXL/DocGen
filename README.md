# DocGen

**DocGen** — генератор официальных документов по шаблонам: заявления, жалобы, претензии, иски, расписки, доверенности и обращения в ведомства. Веб-приложение (Next.js 16 + SQLite), которое работает на вашем сервере или локально на компьютере — без аккаунтов, без отправки данных куда-либо: всё генерируется у вас.

Каталог заточен под **Россию и страны СНГ**: шаблоны ссылаются на реальные нормы (ТК РФ, ГПК, ЗоЗПП, ФЗ-323, ФЗ-59 и аналоги), с предупреждениями о документах, которые принимают только «от руки», и карточками официальных госпорталов (Госуслуги, Diia, eGov, Tunduk, myGov и др.).

**Разделение языков** — ключевое правило DocGen: язык, выбранный при первой настройке, управляет **только интерфейсом**. **Страна** определяет, какие шаблоны доступны, и на каком языке они создаются — на государственном языке выбранной страны (Азербайджан → документ на азербайджанском, интерфейс — какой выбрали).

## Как это работает

| Этап | Что происходит |
|---|---|
| Первая настройка | Два выбора: **язык интерфейса** (русский / English) и **страна** (Россия + 9 стран СНГ). Язык — только язык кнопок и подписей; страна — набор шаблонов и язык будущих документов |
| Каталог | Дерево категорий (работа, суды и споры, медицина, образование, почта, ЖКХ, расписки и доверенности). Показаны шаблоны выбранной страны; у каждого — тип: стандартный / только «от руки» / только через госпортал |
| Форма | Поля под шаблон (текст, дата, выбор), подсказки в виде образцов на языке документа; вверху — уведомление, на каком языке создастся документ |
| Экспорт | .docx (Times New Roman 14 pt, поля по ГОСТ Р 7.0.97-2016, полуторный интервал) и .pdf (юникод-шрифты: кириллица, армянский, азербайджанский); печать — чистой страницей документа без интерфейса |
| Спец-экраны | Красное предупреждение для шаблонов «только от руки» (по требованиям ведомств); карточка госпортала со ссылкой для шаблонов, которые подаются только онлайн |

## Ключевые возможности

- **69 шаблонов** (23 для России + 46 для стран СНГ): отпуска и увольнения по ТК РФ, справки по ст. 62 ТК, претензии по ЗоЗПП, иски по ГПК ст. 131–132, жалобы в Росздравнадзор (ФЗ-323) и прокуратуру (ФЗ-59), ОМС (ФЗ-326), школа (ФЗ-273), академический отпуск, почта (ФЗ-176 ст. 34/37), ЖКХ (ПП-491/ПП-354), расписки и доверенности (ГК ст. 808/185), ФЗ-152 о персональных данных — и универсальные аналоги для Казахстана, Беларуси, Украины, Узбекистана, Кыргызстана, Таджикистана, Армении, Азербайджана, Молдовы.
- **Язык документа = государственный язык страны** (ru, kk, be, uk, uz, kg, tg, hy, az, ro): тела шаблонов, образцы значений и варианты выбора на государственном языке; даты форматируются по правилам языка («02 ноября 2026 г.» / «02.11.2026»); подписи полей формы — на языке интерфейса.
- **Три типа шаблонов**: стандартный (скачивайте и подавайте), HANDWRITTEN_REQUIRED (красный экран: «заполняется от руки»), GOV_PORTAL_ONLY (карточка официального портала страны с прямой ссылкой).
- **Экспорт**: .docx и .pdf, поля и шрифты по ГОСТ Р 7.0.97-2016; адаптированный print-режим (печатается только документ).
- **Самодостаточность**: встроенная БД SQLite с предзаполненным каталогом; никакого интернета, серверов и аналитики; данные не покидают машину.

## Скачать

Готовые сборки — в разделе **[Releases](https://github.com/RVMXL/DocGen/releases)**. Единый выпуск для всех платформ собирается и публикуется CI по пушу тега `v*`.

| Артефакт | Платформа | Что это |
|---|---|---|
| `DocGen-<ver>-server.zip` / `.tar.gz` | любая ОС с Node.js 20+ | Сайт: сервер + каталог, разворачивается на VPS/локальной машине (инструкция внутри архива), есть Dockerfile |
| `DocGen-<ver>-win64-setup.exe` | Windows 10/11 (x64) | Установщик: самодостаточное приложение со встроенным сервером |
| `DocGen-<ver>-linux-x64.AppImage` | Linux (x86_64) | Portable-сборка: запустил — работает |
| `DocGen-<ver>-linux-x64.deb` | Debian/Ubuntu (x64) | Пакет для установки |
| `DocGen-<ver>-mac-arm64.dmg` | macOS Apple Silicon (M1–M4) | Самодостаточное приложение со встроенным сервером |
| `DocGen-<ver>-android.apk` | Android 8.0+ (ARM64) | Клиент к вашему серверу DocGen (адрес сервера вводится при первом запуске) |

**iOS**: сборки нет. Публикация iPhone-приложения требует аккаунта Apple Developer Program (99 $/год), macOS с Xcode и подписи сертификатами Apple — установка «мимо App Store» без аккаунта невозможна в принципе. Пока iOS-версии нет, сайт открывается в Safari; если аккаунт Apple Developer появится, сборка добавляется в этот же релизный конвейер.

## Установка и запуск

### Сайт/сервер (Windows, Linux, macOS)

1. Скачайте `DocGen-<ver>-server.zip` из [релиза](https://github.com/RVMXL/DocGen/releases/latest) и распакуйте.
2. Нужен **Node.js 20+** ([nodejs.org](https://nodejs.org)).
3. Запустите:
   - Linux/macOS: `./start.sh`
   - Windows: `start.cmd`
4. Откройте `http://localhost:3000`.

Скрипт при первом запуске копирует БД с каталогом в `data/` и поднимает сервер на порту из `PORT` (по умолчанию 3000). Пример systemd-юнита, переменные окружения (`PORT`, `HOSTNAME`, `DATABASE_URL`) и Dockerfile — в `README-DEPLOY.txt` внутри архива.

### Windows (x64)

1. Скачайте `DocGen-<ver>-win64-setup.exe` из [релиза](https://github.com/RVMXL/DocGen/releases/latest).
2. Установите и запустите **DocGen** — отдельный браузер и Node.js не нужны: сервер встроен.
3. Если SmartScreen предупреждает (приложение не подписано сертификатом Microsoft): «Подробнее» → «Выполнить в любом случае».

### Linux (x64)

**AppImage** (портативно):

```bash
chmod +x DocGen-<ver>-linux-x64.AppImage
./DocGen-<ver>-linux-x64.AppImage
```

**deb** (Debian/Ubuntu):

```bash
sudo apt install ./DocGen-<ver>-linux-x64.deb
docgen
```

Требуется графическая среда. Если AppImage не стартует на вашей сборке — используйте `--no-sandbox` либо серверную сборку + браузер.

### macOS (Apple Silicon)

1. Скачайте `DocGen-<ver>-mac-arm64.dmg` из [релиза](https://github.com/RVMXL/DocGen/releases/latest).
2. Смонтируйте и перетащите **DocGen** в `Applications`.
3. Первый запуск: сборка не подписана сертификатом Apple Developer — Gatekeeper потребует подтверждения: щёлкните приложение **правой кнопкой → «Открыть»** (один раз), либо снимите карантин: `xattr -cr /Applications/DocGen.app`.
4. Mac на Intel: используйте серверную сборку (`DocGen-<ver>-server.zip`) + браузер.

### Android

Приложение — **клиент к серверу DocGen** (генерация документов выполняется сервером: так работают и сайт, и все платформы). На телефоне нужен доступ к запущенному серверу — локальному в вашей сети (`http://192.168.x.x:3000`) или на VPS с HTTPS.

1. Скачайте `DocGen-<ver>-android.apk` из [релиза](https://github.com/RVMXL/DocGen/releases/latest).
2. Разрешите установку из неизвестных источников для вашего проводника/браузера.
3. При первом запуске введите адрес вашего сервера DocGen (например, `https://docgen.example.com`) — адрес сохраняется; сменить его можно кнопкой «Сервер» на стартовом экране.
4. Дальше — как на сайте: мастер настройки → каталог → форма → .docx/.pdf.

**Обновление**: ставьте новый APK **поверх старого** — данные и настройки сохранятся. Обновления работают потому, что все релизы подписываются **одним и тем же стабильным ключом** (хранится в Secrets CI, в git не попадает; SHA-256 файла ключа зафиксирован пином в workflow — подмена секрета ломает сборку, а не молча подписывает APK чужим ключом).

SHA-256 сертификата подписи (сверяйте после установки):

```
9F:B0:27:A8:A4:EE:DA:28:13:AF:6A:74:26:1B:B0:87:C0:9B:C7:3B:B0:AF:2B:C0:50:C1:5F:ED:B6:1B:1F:46
```

**Требования:** Android 8.0+ (API 26); сеть для доступа к вашему серверу. Разрешение — только `INTERNET`.

### iPhone / iPad

Сборки нет (см. [Скачать](#скачать)). Сайт DocGen открывается в Safari и работает без установки.

## Приватность

- **Ни одна страница, поле и документ никуда не отправляются**: сервер работает локально/на вашем VPS, внешних вызовов из приложения нет (кроме ссылок на официальные госпорталы, которые открываете вы сами).
- Каталог и шаблоны хранятся во встроенной SQLite-БД; сгенерированные файлы скачиваются напрямую браузером.
- Десктоп-версии хранят данные в профиле пользователя (`%APPDATA%/DocGen`, `~/Library/Application Support/DocGen`, `~/.config/DocGen`).

## Сборка из исходников и релизы

```bash
bun install                      # или npm install
DATABASE_URL="file:$(pwd)/db/custom.db" bunx prisma db push
DATABASE_URL="file:$(pwd)/db/custom.db" bun prisma/seed.ts
bun run dev                      # http://localhost:3000
```

Стек: Next.js 16 (App Router) + TypeScript + Tailwind 4 + shadcn/ui + Prisma/SQLite + docx + pdf-lib.

**CI** (GitHub Actions): `ci.yml` — проверка сборки на каждый пуш; `release.yml` — по пушу тега `v*`: сервер-архив, Windows/Linux/macOS (Electron), подписанный Android (ключ из Secrets с SHA-пином, apksigner-сверка сертификата) → единый GitHub Release с SHA-256SUMS.
